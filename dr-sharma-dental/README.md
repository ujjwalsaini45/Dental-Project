# dr-sharma-dental

Scaffolded project for Dr. Sharma Dental Clinic.

Structure:

dr-sharma-dental/
- frontend/
  - index.html
  - style.css
  - main.js
  - images/
- backend/
  - server.js
  - package.json
  - .env.example
  - routes/appointments.js
  - controllers/appointmentController.js
  - models/Appointment.js

Quick start (backend):

1. cd backend
2. npm install
3. cp .env.example .env (and edit)
4. npm run dev

The frontend is static in `frontend/`. Replace placeholder content with your original `hello.html` if you prefer a verbatim copy.
